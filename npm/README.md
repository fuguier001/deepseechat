# dsc

Bridge local AI coding agents (Agent CLI, Cursor, Gemini CLI, Codex) to messaging platforms (Feishu/Lark, DingTalk, Slack, Telegram, Discord, LINE, WeChat Work).

Chat with your AI dev assistant from anywhere.

## Install

```bash
npm install -g dsc
```

## Usage

```bash
# Create config
dsc --version

# Edit config.toml, then run
dsc
dsc -config /path/to/config.toml
```
